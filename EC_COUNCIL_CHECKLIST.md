# EC-Council ECE — Author Security Tool: checklist

**Non è un'approvazione né una garanzia di 40 ECE.** Le condizioni viste nel portale prevedono nuova utility open source di security, prova della paternità tramite link, pubblicazione pubblica e feedback/verifica della comunità.

- [ ] L'autore ha esaminato il codice derivato dai suoi script originali, corretto eventuali problemi e verificato la legittima titolarità prima di attribuirsene la paternità.
- [ ] Il repository GitHub è pubblico e il profilo dell'autore è riconoscibile; include cronologia dei commit e release/tag.
- [ ] Suite offline eseguita su Windows con screenshot o log di esito.
- [ ] Esecuzione live v4 sul PC: verificare fonti attive e tipi realmente presenti in `sources.csv`, senza dichiarare operative le fonti non testate.
- [ ] Evidenze di comunità reali e verificabili (issue/review/contributi, se ottenuti). Non simulare feedback o stelle.
- [ ] Non pubblicare API key, IOC esportati dalle fonti senza diritto, risultati interni aziendali o dati personali.
- [ ] Prima della richiesta ECE confermare a EC-Council come considera i repository GitHub e quale verifica comunitaria è accettata.
- [ ] Inviare il link al repository e soltanto evidenze veritiere sulla paternità e sulla verifica.
